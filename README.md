# 빵방곳곳 NFC 랜딩페이지

운영 사이트 저장 버전 33에서 받은 웹페이지 파일입니다. 별도 라이브러리 설치 없이 수정할 수 있습니다.

## 실행

1. ZIP 파일을 압축 해제합니다.
2. `index.html`을 브라우저에서 열어 화면을 확인합니다.
3. 코드는 Visual Studio Code 또는 텍스트 편집기에서 수정합니다.

위치 기반 주변 빵집 기능은 브라우저 보안 설정 때문에 파일을 직접 열었을 때 제한될 수 있습니다. 이 기능까지 테스트하려면 프로젝트 폴더에서 터미널을 열고 `python -m http.server 8000`을 실행한 다음, 브라우저에서 `http://localhost:8000`을 여세요.

## 주요 파일

- `index.html`: 화면 구조와 문구
- `styles.css`: 색상, 글꼴, 배치, 모바일 화면 디자인
- `app.js`: 매장 검색과 매장 카드 동작
- `data.js`: 빵집 데이터
- `regional-top5.js`: 지역별 추천 데이터
- `features.js`: 저장, 방문 스탬프, 위치 추천, 제보 등
- `bread-cup.js`: 빵 월드컵
- `assets/`: 이미지, SVG 아이콘, 월드컵 빵 이미지, Jalnan 글꼴

파일 이름이나 폴더 위치를 바꾸면 HTML/CSS의 경로도 함께 수정해야 합니다. Google Fonts는 인터넷 연결 시 추가로 불러옵니다.


## 지역 추천 UI 개선
Pretendard CDN을 사용합니다(인터넷 연결 필요). 지역 추천 가나다순/저장 우선 정렬, 북마크 아이콘, 헤더 로고, 모바일 2열 카드가 적용됐습니다. 기존 localStorage 키 및 지역 데이터는 유지됩니다.
